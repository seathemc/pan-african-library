## SEARCH STRATEGIES

### Internet Archive
1. Go to [archive.org](https://archive.org)
2. Search by title or author name
3. Look for "Borrow" or "Read Online" options
4. Create free account if needed
5. Borrow for 1-14 days (like a library)

### Finding Specific Works
Use these search formats:
- `"author name" "book title"`
- Add `site:archive.org` to Google searches
- Try both English and original language titles
- Search for "African Writers Series" for classic works

### Tips for Success
- Check multiple editions if one isn't available
- Join waitlist for popular titles
- Return books early to help others
- Download for offline reading when borrowed

## NOTES ON USING THESE RESOURCES

### Internet Archive Borrowing
- Like borrowing from a library
- Limited copies available at once
- Can join waitlist for popular titles
- Respect copyright by not sharing downloads

### Copyright Reminder
- Project Gutenberg = fully free (public domain)
- Internet Archive = borrowing only (copyright protected)
- Recent books = purchase or library borrow
- Always use legal sources

### Best Practices
1. Start with public domain works (Project Gutenberg)
2. Use Internet Archive for classics
3. Check your library for everything
4. Purchase recent works to support authors
5. Share this list with others!
